# Ashutosh Kumar — Portfolio Website

Source for my personal portfolio, hosted on **GitHub Pages** and mapped to my custom domain: [https://asu2sh.com](https://asu2sh.com)

## About

I'm a **Backend & Data Engineer** specializing in **Python**, **ETL pipelines**, and **LLM integration**. This site highlights:

- Backend systems, data engineering, and AI integration work
- Tech stack and skills
- Résumé download
- Contact links (email, GitHub, LinkedIn, LeetCode)

---

## Features

- Single self-contained `index.html` — no build step, no dependencies, no external requests
- Dark theme by default, with a persistent light/dark switcher (`localStorage` + `prefers-color-scheme` fallback)
- Fully responsive, accessible (semantic landmarks, skip link, focus-visible states), and print-friendly
- Résumé download front and center

---

## Tech Stack

- Plain HTML5 + CSS (inlined, no framework)
- GitHub Pages (free hosting)
- [Spaceship.com](https://spaceship.com) for the domain
